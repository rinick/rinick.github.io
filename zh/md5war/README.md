# MD5作战 v1.20 HTML5 复刻版

这是一个普通的静态 HTML5 应用，不包含 Ruffle、WebAssembly 或运行时 SWF 转换。浏览器只执行 `app.js`，原始 `md5war.swf` 保留在目录中作为版本和素材来源，不参与页面运行。

来自原 SWF 的内容包括：

- 700×500 舞台、左侧背景和标签的 SVG 矢量图
- 单个自包含 SVG 文件中的 CGFan 标志 31 帧、12 fps 矢量动画
- 全部角色表情直接使用原始 GIF；对应 SVG 以 `GIF名-原帧号.svg` 命名并保留作比对
- 由 CSS 实时绘制、按剩余体力连续变色的血条
- 原 AS2 的特殊中文 MD5 算法、属性生成、技能和逐帧战斗流程

两个姓名框使用原生 HTML 输入，因此支持现代浏览器的中文输入法。点击 `Fight` 或在输入完成后按回车均可开始；双方属性会立即出现，战报仍按原版的帧间隔播放。

原版隐藏功能也已保留：右侧输入 `[实力评估]` 时，会按原算法依次与“测试0”到“测试99”对战并输出实力评分。

原 SWF 的姓名和战报使用设备“宋体”而非嵌入字体，HTML5 版同样使用系统字体，不额外下载字体文件。

## 运行

应用不需要安装或编译依赖。通过任意静态 HTTP 服务器提供本目录即可，例如：

```bash
python3 -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>。

在 `rinick.github.io` 仓库中，可运行仓库自带的开发服务器并打开 <http://127.0.0.1:4000/zh/md5war/>；站点页面位于 <http://127.0.0.1:4000/zh/md5.html>。

原 SWF 中的域名保护和旧站外链没有移植；纯 HTML5 版本不读取当前域名，也不发起外部网络请求。
