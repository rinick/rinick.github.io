快捷键可以在“设置 → 键盘快捷键”中修改。下表列出默认键位；标有“桌面版”的功能需要 Electron 桌面应用。

### 方向键的特殊操作

上一手、下一手和切换分支的方向键可以配合修饰键使用：

| 按法 | 效果 |
| --- | --- |
| 方向键 | 前进或后退 1 手，或切换 1 个分支 |
| `Shift + 方向键` | 一次跳过 10 手或 10 个分支 |
| `Ctrl + 方向键` | 直接跳到开头、末尾、第一个或最后一个分支 |

macOS 上可使用 `Command` 代替 `Ctrl`。为了保留这些跳转方式，导航功能的自定义快捷键不会记录 `Ctrl` 或 `Shift`。

### 标记工具的特殊操作

| 操作 | 效果 |
| --- | --- |
| 双击棋盘上的棋子 | 将当前文字或图形标记应用到整块相连同色棋 |
| 使用擦除工具双击标记 | 擦除与该点相连、类型和文字均相同的标记 |
| 双击工具栏中的擦除按钮 | 清除当前节点的全部标记 |
| 使用标记工具右击已有标记 | 擦除该点的标记，无需切换到擦除工具 |
| 使用文字工具右击空白点 | 添加当前文字，但不触发标记文字的自动递增 |

### 其他特殊操作

- `Ctrl + V`：从剪贴板打开 SGF 或图片；这是保留快捷键，不能改作其他功能；
- `Esc`：退出数子结果，或回到“黑白交替”工具；
- `Shift + 点击棋盘`：点击已有棋子可跳到它落下的那一手，点击后续着手可向后跳转；
- 鼠标滚轮：在棋盘上向上/向下滚动，可查看上一手/下一手；
- `Alt + 点击推荐点`：显示该推荐点的主要变化（桌面版）。

### 文件与棋局

| 功能 | 默认快捷键 |
| --- | --- |
| 打开 | `Ctrl + O` |
| 保存 | `Ctrl + S` |
| 棋局信息 | `Ctrl + I` |

### 棋谱导航

| 功能 | 默认快捷键 |
| --- | --- |
| 上一手 | `↑` |
| 下一手（优先主分支） | `↓` |
| 下一手（优先当前分支） | 未设置 |
| 前一分支 | `←` |
| 后一分支 | `→` |

### 落子与标记

| 功能 | 默认快捷键 |
| --- | --- |
| 停一手 | `P` |
| 黑白交替 | `1` |
| 放置黑子 / 白子 | `2` / `3` |
| 替换着手 | `4` |
| 添加文字 / 圆形 / 方形 / 三角 / 叉形 | `5` / `6` / `7` / `8` / `9` |
| 擦除标记 | `0` |

### 分支操作

| 功能 | 默认快捷键 |
| --- | --- |
| 将当前分支移为主分支 | `\` |
| 分支左移 / 右移 | 未设置 |
| 修剪其他分支 | 未设置 |
| 删除当前分支 | `Delete` |

### 显示与分析

| 功能 | 默认快捷键 |
| --- | --- |
| 显示坐标 | `` ` `` |
| 显示下一手 | `Q` |
| 显示手数 | `R` |
| 显示评论 | `O` |
| 复盘 / 编辑模式（桌面版） | `W` |
| 显示分析圆点（桌面版） | `E` |
| 显示地域（桌面版） | `T` |
| 显示目差 / 损失目数 / 胜率（桌面版） | `Y` / `U` / `I` |
| 开始或停止分析（桌面版） | `Space` |
| 深度分析（桌面版） | `Shift + Space` |
| 落下最佳推荐手（桌面版） | `Enter` |
