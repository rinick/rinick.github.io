本页汇总乌鹭应用内的操作提示，并按适用平台分类。

### 通用操作

| 功能 | 操作 |
| --- | --- |
| 快速跳转 | 按住 `Shift` 点击棋盘上的棋子，可以跳到它落下的那一手；点击后续着手可以向后跳转 |
| 连片标记 | 使用文字或图形标记工具时，双击棋子会将当前标记应用到整块相连同色棋 |
| 文字标记递增 | 文字标记会自动切换到下一个文字，例如 `A → B`、`1 → 2`；使用右键添加时保持当前文字不变 |
| 修正错记着手 | 选中错误的着手并使用“替换着手”。乌鹭会退回上一手，可以直接纠正落点，无需重新摆放后续着手 |
| 图片录入 | 打开文件时选择棋盘图片，即可识别盘面并生成 SGF。详细说明见 [棋谱图像识别](./scan.html) |
| 剪贴板导入 | 按 `Ctrl + V` 可以直接打开剪贴板中的 SGF 文本或图片 |

### 网页版

| 功能 | 操作 |
| --- | --- |
| 竖屏极简模式 | 极简模式在竖屏时会自动旋转 `90°`，在手机或平板上记谱时可以为棋盘保留更大的显示区域 |
| 终盘目数估算 | 在右下窗口中右键点击一手棋，可以对该局面进行目数估算；这项功能仅适用于终盘局面 |

### 桌面版 AI 分析

| 功能 | 操作 |
| --- | --- |
| 深度分析 | 按住 `Shift` 点击棋盘右下角的分析按钮，可以忽略“最大访问数”并持续分析当前局面 |
| 着手价值 | “推荐点叠加”可以显示着手的“价值”；该数值会受到热点区域死活和先后手影响，不完全等同于官子价值 |
| 热点区域 | 开启“热点区域”后，蓝色表示双方争夺的要点，灰色表示可能需要弃给对方的区域 |
| 调整分析速度 | 分析较慢时，可以在“AI配置”中选择较小的 KataGo 模型，例如 `kata1-b18`；降低“快速访问数”也能缩短整盘图表的生成时间 |
| 主要变化预览 | 将鼠标停在推荐点上可以预览后续主要变化；按住 `Alt` 点击推荐点也可以直接显示 |

完整键位和鼠标操作见 [快捷操作](./shortcut.html)，分析数值与图表说明见 [AI分析](./analysis.html)。
