Tastenkürzel können unter **Einstellungen → Tastenkombinationen** geändert werden. Die folgenden Tabellen zeigen die Standardbelegung; mit **Desktop** markierte Funktionen benötigen die Electron-Desktop-App.

### Sonderfunktionen der Pfeiltasten

Die Pfeiltasten für Zugnavigation und Variantenwechsel können mit Modifikatortasten kombiniert werden:

| Eingabe | Aktion |
| --- | --- |
| Pfeiltaste | Einen Zug vor oder zurück gehen oder eine Variante wechseln |
| `Shift + Pfeiltaste` | 10 Züge oder 10 Varianten überspringen |
| `Ctrl + Pfeiltaste` | Direkt zum Anfang, Ende, zur ersten oder letzten Variante springen |

Unter macOS kann `Command` anstelle von `Ctrl` verwendet werden. Damit diese Navigation erhalten bleibt, zeichnen benutzerdefinierte Kürzel für Navigationsfunktionen `Ctrl` und `Shift` nicht auf.

### Sonderfunktionen der Markierungswerkzeuge

| Geste | Aktion |
| --- | --- |
| Einen Stein doppelklicken | Aktuellen Text oder aktuelle Form auf die gesamte verbundene Gruppe gleicher Farbe anwenden |
| Eine Markierung mit dem Löschwerkzeug doppelklicken | Verbundene Markierungen mit gleichem Typ und Text löschen |
| Die Löschen-Schaltfläche in der Werkzeugleiste doppelklicken | Alle Markierungen des aktuellen Knotens entfernen |
| Mit einem Markierungswerkzeug eine vorhandene Markierung rechtsklicken | Markierung am Punkt löschen, ohne zum Löschwerkzeug zu wechseln |
| Mit dem Textwerkzeug einen leeren Punkt rechtsklicken | Aktuellen Text hinzufügen, ohne die automatische Erhöhung auszulösen |

### Weitere Sonderaktionen

- `Ctrl + V`: SGF oder Bild aus der Zwischenablage öffnen; dieses Kürzel ist reserviert und kann nicht neu belegt werden
- `Esc`: Zählergebnis verlassen oder zum Werkzeug **Abwechselnd spielen** zurückkehren
- `Shift + Klick` auf das Brett: bei einem vorhandenen Stein zu dessen Zug springen, bei einem späteren Zug dorthin vorgehen
- Mausrad über dem Brett: vorherigen oder nächsten Zug anzeigen
- `Alt + Klick` auf einen empfohlenen Zug: dessen Hauptvariante anzeigen (**Desktop**)

### Dateien und Partie

| Funktion | Standardkürzel |
| --- | --- |
| Öffnen | `Ctrl + O` |
| Speichern | `Ctrl + S` |
| Partieinformationen | `Ctrl + I` |

### Partienavigation

| Funktion | Standardkürzel |
| --- | --- |
| Vorheriger Zug | `↑` |
| Nächster Zug (Hauptvariante bevorzugen) | `↓` |
| Nächster Zug (aktuelle Variante bevorzugen) | Nicht zugewiesen |
| Vorherige Variante | `←` |
| Nächste Variante | `→` |

### Züge und Markierungen

| Funktion | Standardkürzel |
| --- | --- |
| Passen | `P` |
| Abwechselnd spielen | `1` |
| Schwarzen / weißen Stein setzen | `2` / `3` |
| Zug ersetzen | `4` |
| Text / Kreis / Quadrat / Dreieck / Kreuz hinzufügen | `5` / `6` / `7` / `8` / `9` |
| Markierung löschen | `0` |

### Variantenaktionen

| Funktion | Standardkürzel |
| --- | --- |
| Aktuelle Variante zur Hauptvariante machen | `\` |
| Variante nach links / rechts verschieben | Nicht zugewiesen |
| Andere Varianten beschneiden | Nicht zugewiesen |
| Aktuelle Variante löschen | `Delete` |

| Koordinaten anzeigen | `` ` `` |
| Nächsten Zug anzeigen | `Q` |
| Zugnummern anzeigen | `R` |
| Notizen anzeigen | `O` |
| Prüf- / Bearbeitungsmodus (**Desktop**) | `W` |
| Analysekreise anzeigen (**Desktop**) | `E` |
| Gebiet anzeigen (**Desktop**) | `T` |

| Besten Zug spielen (**Desktop**) | `Enter` |
