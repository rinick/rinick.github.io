Ulugo のアプリ内に表示される操作ヒントを、対応プラットフォーム別にまとめています。

### 共通操作

| 機能 | 操作 |
| --- | --- |
| 素早く移動 | `Shift` を押しながら盤上の石をクリックすると、その石が打たれた手へ移動する。先の着手をクリックすると、その手まで進む |
| 一団へマーク | 文字または図形ツールを選び、石をダブルクリックすると、同色で連結した一団すべてに現在のマークを付ける |
| 文字マークの自動増加 | 文字マークは `A → B`、`1 → 2` のように自動で進む。右クリックで追加した場合は現在の文字を維持する |
| 誤記した着手を修正 | 誤った手を選択して **着手を置換** を使う。Ulugo が一手前へ戻るため、後続の着手を並べ直さずに落点を修正できる |
| 画像から入力 | ファイルを開く際に碁盤画像を選ぶと、盤面を認識して SGF を作成する。詳細は [盤面画像認識](./scan.html) を参照 |
| クリップボードから入力 | `Ctrl + V` を押すと、クリップボード内の SGF テキストまたは画像を直接開く |

### ウェブ版

| 機能 | 操作 |
| --- | --- |
| 縦画面のミニマルモード | 縦画面ではミニマルモードが `90°` 回転し、スマートフォンやタブレットで棋譜を記録するときに盤面を広く表示する |
| 終局時の地合い推定 | 右下のパネルで着手を右クリックすると、その局面の地合いを推定する。この機能は終局局面専用 |

### デスクトップ版の AI 解析

| 機能 | 操作 |
| --- | --- |
| 深い解析 | `Shift` を押しながら盤面右下の解析ボタンをクリックすると、**最大訪問数**を無視して現在局面を継続的に解析する |
| 着手の価値 | **候補手オーバーレイ**で着手の**価値**を表示できる。ホットゾーンの死活や先手後手の影響を受けるため、ヨセの価値とは完全には一致しない |
| ホットゾーン | **ホットゾーン**を有効にすると、双方が争う要点を青、相手に譲る可能性がある範囲を灰色で表示する |
| 解析速度 | 解析が遅い場合は **AI 設定**で `kata1-b18` など小さな KataGo モデルを選ぶ。**高速訪問数**を下げると全局グラフの作成時間も短くなる |
| 主変化プレビュー | 候補手にマウスを重ねると主変化を表示する。候補手を `Alt` クリックして直接表示することもできる |

すべてのキーとマウス操作は [ショートカット操作](./shortcut.html)、解析値とグラフの説明は [AI 解析](./analysis.html) を参照してください。
