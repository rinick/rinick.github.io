このページでは、Ulugo に表示されるヒントをプラットフォーム別にまとめています。

### 一般操作

| 機能 | 操作 |
| --- | --- |
| クイック移動 | `Shift` を押しながら盤上の石をクリックすると、その石が打たれた着手へ移動できます。後続の着手をクリックすると、その手まで進みます |
| 連結した石へのマーク | 文字または図形マークツールの使用中に石をダブルクリックすると、同色で連結した石全体に現在のマークを付けます |
| 文字マークの自動増加 | 文字マークは `A → B`、`1 → 2` のように自動で次へ進みます。右クリックで追加すると現在の文字を維持します |
| 着手を挿入 | **着手を挿入**を使うと、同じ一時分岐に着手を追加できます。右クリックすると着手を削除し、削除した位置の一手前へ移動します |
| 着手編集中の移動 | **着手を挿入**または**着手を削除**を選んでも現在の局面は変わりません。両ツールを切り替えたり、現在の分岐やそれ以前の幹を選んだりしても編集は続きます。別の分岐を選ぶと終了します |
| 画像の取り込み | ファイルを開くときに盤面画像を選ぶと、盤面を認識して SGF を作成します。詳しくは [盤面画像認識](./scan.html) をご覧ください |
| クリップボードからの読み込み | `Ctrl + V` を押すと、クリップボード内の SGF テキストまたは画像を直接開けます |

### ウェブ版

| 機能 | 操作 |
| --- | --- |
| 縦向きのミニマルモード | 縦向きではミニマルモードが自動的に `90°` 回転し、スマートフォンやタブレットでの記譜時に盤面を広く表示します |
| 終局時の地合い推定 | 右下のウィンドウで着手を右クリックすると、その局面の地合いを推定します。この機能は終局局面専用です |

### デスクトップ版の AI 解析

| 機能 | 操作 |
| --- | --- |
| 詳細解析 | `Shift` を押しながら盤面右下の解析ボタンをクリックすると、**最大訪問数**を無視して現在の局面を解析し続けます |
| 着手の価値 | **候補手オーバーレイ**では着手の**価値**を表示できます。ホットゾーン内の死活や先後が影響するため、ヨセの価値とは一致しません |
| ホットゾーン | **ホットゾーン**を有効にすると、双方が争う重要な領域を青、放棄が必要な可能性のある領域を灰色で表示します |
| 解析速度の調整 | 解析が遅い場合は、**AI設定**で `kata1-b18` などの小さい KataGo モデルを選択してください。**高速訪問数**を減らすと、棋譜全体のグラフ生成も短縮できます |
| 主要変化のプレビュー | 候補手にマウスを合わせると主要変化をプレビューできます。`Alt` を押しながら候補手をクリックしても直接表示できます |

キーボードとマウスの全操作は [ショートカット操作](./shortcut.html)、解析値とグラフの説明は [AI 解析](./analysis.html) をご覧ください。
