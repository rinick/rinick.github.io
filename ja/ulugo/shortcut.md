キーボードショートカットは **設定 → キーボードショートカット** で変更できます。以下は初期設定です。**デスクトップ版** と記載された機能には Electron デスクトップアプリが必要です。

### 矢印キーの修飾操作

着手移動と分岐切り替えの矢印キーには修飾キーを組み合わせられます。

| 入力 | 操作 |
| --- | --- |
| 矢印キー | 1 手前後へ移動、または分岐を 1 つ切り替える |
| `Shift + 矢印キー` | 10 手または 10 分岐単位で移動する |
| `Ctrl + 矢印キー` | 先頭、末尾、最初の分岐、最後の分岐へ直接移動する |

macOS では `Ctrl` の代わりに `Command` を使用できます。これらの移動操作を維持するため、ナビゲーション用のカスタムショートカットには `Ctrl` と `Shift` が記録されません。

### マークアップの特殊操作

| 操作 | 結果 |
| --- | --- |
| 盤上の石をダブルクリック | 現在の文字または図形マークを、同色で連結した一団すべてに付ける |
| 消去ツールでマークをダブルクリック | その点に連結し、種類と文字が同じマークを消去する |
| ツールバーの消去ボタンをダブルクリック | 現在のノードにある全マークを消去する |
| マークツール使用中に既存マークを右クリック | 消去ツールへ切り替えず、その点のマークを消去する |
| 文字ツールで空点を右クリック | 現在の文字を追加するが、マーク文字の自動増加は行わない |

### その他の特殊操作

- `Ctrl + V`: クリップボードから SGF または画像を開く。予約済みのため他の機能には割り当て不可
- `Esc`: 地合い計算結果を閉じる、または **交互に着手** ツールへ戻る
- 盤面を `Shift + クリック`: 既存の石ならその着手へ、先の着手なら該当する手まで進む
- 盤面上でマウスホイール: 前の手または次の手へ移動する
- 候補手を `Alt + クリック`: その主変化を表示する（**デスクトップ版**）

### ファイルと対局情報

| 機能 | 初期ショートカット |
| --- | --- |
| 開く | `Ctrl + O` |
| 保存 | `Ctrl + S` |
| 対局情報 | `Ctrl + I` |

### 棋譜ナビゲーション

| 機能 | 初期ショートカット |
| --- | --- |
| 前の手 | `↑` |
| 次の手（主分岐優先） | `↓` |
| 次の手（現在の分岐優先） | 未設定 |
| 前の分岐 | `←` |
| 次の分岐 | `→` |

### 着手とマークアップ

| 機能 | 初期ショートカット |
| --- | --- |
| パス | `P` |
| 交互に着手 | `1` |
| 黒石 / 白石を置く | `2` / `3` |
| 着手を置換 | `4` |
| 文字 / 丸 / 四角 / 三角 / バツを追加 | `5` / `6` / `7` / `8` / `9` |
| マークアップを消去 | `0` |

### 分岐操作

| 機能 | 初期ショートカット |
| --- | --- |
| 現在の分岐を主分岐へ移動 | `\` |
| 分岐を左 / 右へ移動 | 未設定 |
| 他の分岐を剪定 | 未設定 |
| 現在の分岐を削除 | `Delete` |

### 表示と解析

| 機能 | 初期ショートカット |
| --- | --- |
| 座標を表示 | `` ` `` |
| 次の手を表示 | `Q` |
| 手数を表示 | `R` |
| コメントを表示 | `O` |
| 検討 / 編集モード（**デスクトップ版**） | `W` |
| 解析候補の円を表示（**デスクトップ版**） | `E` |
| 地域を表示（**デスクトップ版**） | `T` |
| 目差 / 損失目数 / 勝率を表示（**デスクトップ版**） | `Y` / `U` / `I` |
| 解析を開始 / 停止（**デスクトップ版**） | `Space` |
| 深い解析（**デスクトップ版**） | `Shift + Space` |
| 最善候補を着手（**デスクトップ版**） | `Enter` |
