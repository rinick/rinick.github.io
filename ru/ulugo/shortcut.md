Сочетания клавиш можно изменить в разделе **Настройки → Сочетания клавиш**. В таблицах указаны значения по умолчанию; действия с пометкой **Настольная версия** требуют приложения Electron.

### Модификаторы стрелок

Стрелки для навигации по ходам и переключения веток поддерживают клавиши-модификаторы:

| Ввод | Действие |
| --- | --- |
| Стрелка | Перейти на 1 ход вперед или назад либо переключиться на 1 ветку |
| `Shift + стрелка` | Перейти на 10 ходов или 10 веток |
| `Ctrl + стрелка` | Сразу перейти к началу, концу, первой или последней ветке |

В macOS вместо `Ctrl` можно использовать `Command`. Чтобы сохранить эти способы навигации, пользовательские сочетания для соответствующих функций не записывают `Ctrl` и `Shift`.

### Особые действия с разметкой

| Действие | Результат |
| --- | --- |
| Дважды щелкнуть камень | Применить текущий текст или фигуру ко всей связанной группе камней того же цвета |
| Дважды щелкнуть разметку инструментом стирания | Удалить связанную разметку того же типа и с тем же текстом |
| Дважды щелкнуть кнопку стирания на панели инструментов | Удалить всю разметку текущего узла |
| Щелкнуть существующую разметку правой кнопкой с выбранным инструментом разметки | Удалить разметку в точке без переключения на инструмент стирания |
| Щелкнуть пустую точку правой кнопкой с выбранным текстовым инструментом | Добавить текущий текст без автоматического перехода к следующему |

### Другие особые действия

- `Ctrl + V`: открыть SGF или изображение из буфера обмена; это сочетание зарезервировано и не переназначается;
- `Esc`: закрыть результат подсчета или вернуться к инструменту **Чередовать ходы**;
- `Shift + щелчок` на доске: на существующем камне перейти к поставившему его ходу, на будущем ходе — перейти вперед к нему;
- колесо мыши над доской: предыдущий или следующий ход;
- `Alt + щелчок` на рекомендованном ходе: показать его главный вариант (**Настольная версия**).

### Файлы и партия

| Функция | Сочетание по умолчанию |
| --- | --- |
| Открыть | `Ctrl + O` |
| Сохранить | `Ctrl + S` |
| Информация о партии | `Ctrl + I` |

### Навигация по партии

| Функция | Сочетание по умолчанию |
| --- | --- |
| Предыдущий ход | `↑` |
| Следующий ход (предпочитать главную ветку) | `↓` |
| Следующий ход (предпочитать текущую ветку) | Не назначено |
| Предыдущая ветка | `←` |
| Следующая ветка | `→` |

### Ходы и разметка

| Функция | Сочетание по умолчанию |
| --- | --- |
| Пас | `P` |
| Чередовать ходы | `1` |
| Поставить черный / белый камень | `2` / `3` |
| Заменить ход | `4` |
| Добавить текст / круг / квадрат / треугольник / крест | `5` / `6` / `7` / `8` / `9` |
| Стереть разметку | `0` |

### Действия с ветками

| Функция | Сочетание по умолчанию |
| --- | --- |
| Сделать текущую ветку главной | `\` |
| Переместить ветку влево / вправо | Не назначено |
| Обрезать другие ветки | Не назначено |
| Удалить текущую ветку | `Delete` |
