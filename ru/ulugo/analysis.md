Настольное приложение Ulugo анализирует партии локально и показывает рекомендованные ходы, территорию, разницу в очках и изменение вероятности победы. В веб-версии эта функция недоступна.

Перед первым использованием завершите [настройку среды ИИ](./katago.html).

### Запуск анализа

Откройте партию и нажмите кнопку с молнией в правом нижнем углу доски или клавишу `Space`:

- Ulugo быстро проходит по существующим ходам, чтобы построить графики всей партии;
- затем продолжается анализ текущей позиции, а результат стабилизируется по мере вычислений;
- готовые узлы кэшируются и при повторном посещении не вычисляются заново;
- повторное нажатие `Space` останавливает анализ.

![!600](/en/ulugo/analysis.webp)

Удерживайте `Shift` при нажатии кнопки анализа или нажмите `Shift + Space`, чтобы включить **глубокий анализ**. Он продолжает вычисления текущей позиции и подходит для подробного сравнения сложных вариантов.

### Рекомендованные ходы

Рекомендованные ходы — кандидаты текущего поиска. Круги показывают их порядок; настройка **Наложение рекомендуемых ходов** может дополнительно выводить следующие значения:

| Параметр | Описание |
| --- | --- |
| Изменение счета | Оценка изменения относительно лучшего кандидата. `0` — базовый уровень; `-3.0` означает потерю примерно 3 очков |
| Изменение вероятности победы | Изменение относительно лучшего кандидата. `0%` — базовый уровень; отрицательное значение означает снижение вероятности |
| Счет | Ожидаемая итоговая разница после хода с точки зрения игрока, чья очередь ходить; положительное значение означает преимущество, отрицательное — отставание |
| Посещения | Число поисковых посещений кандидата. Отражает распределение вычислений и устойчивость результата, но не равно качеству хода само по себе |
| Ценность | Ценность хода относительно паса. Она похожа на ценность готэ-йосэ, но не полностью ей соответствует |

Наложение может одновременно показывать до двух значений. Настройка **Минимум посещений для наложения** скрывает кандидатов, по которым поиск еще недостаточен для стабильной оценки.

Нажмите `Enter`, чтобы сыграть текущий лучший ход. Другие команды приведены на странице [Сочетания клавиш и жесты](./shortcut.html).

### Главный вариант

Наведите указатель на рекомендованный ход, чтобы увидеть на доске ожидаемое ИИ продолжение. Тот же вариант можно открыть с помощью `Alt`-клика.

**Задержка предпросмотра главного варианта** задает время наведения до появления последовательности. Значение `0` отключает предпросмотр при наведении, но не `Alt`-клик.

Главный вариант — основная линия текущего поиска, а не единственное возможное продолжение. Он может меняться по мере дальнейших вычислений.

### Графики на правой панели

На правой панели доступны три графика, которые можно показывать отдельно или вместе:

| График | Описание |
| --- | --- |
| Разница в очках | Ожидаемая итоговая разница после каждого хода с учетом коми и текущих правил. Выше средней линии — `B+`, ниже — `W+` |
| Потеря очков | Ожидаемая потеря из-за сыгранного хода. Чем выше столбец, тем больше потеря; изменения свыше примерно 1 очка выделяются |
| Вероятность победы | Ожидаемая вероятность победы черных после каждого хода. Для белых она равна `100% − вероятность черных`; `50%` — равная позиция |

![](/en/ulugo/chart-.webp)

При наведении на график отображаются номер хода, разница в очках, вероятность победы обеих сторон и потеря на этом ходу. Нажмите, чтобы перейти непосредственно к ходу, или прокручивайте колесо над графиком для перехода вперед и назад.

При большом преимуществе вероятность победы может долго оставаться около `0%` или `100%`. В такой ситуации разница и потеря очков лучше подходят для сравнения качества отдельных ходов.

### Территория и горячая зона

| Отображение | Описание |
| --- | --- |
| Территория | Полупрозрачные цвета показывают области, которые предположительно контролирует каждая сторона. Это текущая оценка анализа, а не подтвержденный итоговый подсчет |
| Горячая зона | Синим отмечены ключевые спорные области или области, которые можно потерять после ошибки. Серым — части, которыми, возможно, придется пожертвовать ради более важной области |

![!600](/en/ulugo/hot-zone.webp)

### Если анализ идет медленно

Сначала уменьшите число посещений для обычного анализа или полного прохода по партии. Модели, оборудование и параметры запуска описаны на странице [Среда выполнения и оборудование](./katago.html).
