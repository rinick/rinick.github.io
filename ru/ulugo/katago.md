KataGo — движок го с открытым исходным кодом без собственного графического интерфейса. Настольное приложение Ulugo запускает его локально, получает кандидаты, территорию, счет и другие данные анализа, а затем выводит их в интерфейсе разбора.

При первом использовании Ulugo автоматически устанавливает и выбирает рекомендованную сборку KataGo и модель. Большинству пользователей не требуется ручная настройка. После завершения подготовки перейдите к странице [ИИ-анализ](./analysis.html).

### KataGo и модели

Для ИИ-анализа нужны два компонента:

| Компонент | Назначение |
| --- | --- |
| KataGo | Программа, выполняющая анализ на компьютере |
| Модель | Файл нейронной сети, содержащий игровую силу и оценку позиций |

Оба компонента работают локально. Для первой загрузки требуется подключение к Интернету; после установки партии можно анализировать без сети.

### Требования к оборудованию

KataGo может использовать GPU или работать только на CPU. GPU не обязателен, но обычно заметно ускоряет анализ.

| Компьютер | Рекомендуемый вариант |
| --- | --- |
| Относительно новый дискретный или встроенный GPU | Сначала попробовать `OpenCL`: он совместим с широким набором оборудования |
| Новый GPU NVIDIA с подходящими драйверами и библиотеками | Попробовать `TensorRT` или `CUDA` |
| Подходящего GPU нет, CPU поддерживает AVX2 | Выбрать `CPU` |
| Старый CPU без AVX2 | Выбрать `Старый CPU`; анализ будет медленнее |
| macOS | Установка через Homebrew; на Apple Silicon используется подходящая системная сборка |

![!500](/en/ulugo/ai-config.webp)

Крупные модели и одновременный анализ нескольких задач обычно требуют больше памяти. При нехватке памяти или медленной работе начните с модели с пометкой **самая быстрая**. Оставьте на диске не менее нескольких сотен МБ; для нескольких моделей потребуется больше места.

Подробности о вычислительных бэкендах приведены в [официальной документации KataGo](https://github.com/lightvector/KataGo#opencl-vs-cuda-vs-tensorrt-vs-eigen).

### Автоматическая настройка и ручной выбор

При первом запуске Ulugo автоматически загружает и выбирает рекомендованную сборку и модель. Во время загрузки сохраняйте подключение к сети; после нее анализ работает офлайн.

Чтобы попробовать другую сборку или модель, откройте **Настройки ИИ**:

1. в разделе **Установки KataGo** выберите и установите подходящую сборку;
2. в разделе **Модели KataGo** установите и выберите модель;
3. нажмите **Сохранить**, вернитесь к доске и запустите анализ.

Некоторые GPU-сборки при первом запуске выполняют настройку производительности. В это время интерфейс может реагировать медленно; после завершения повторная настройка обычно не требуется.

### Основные параметры

| Параметр | Описание |
| --- | --- |
| Максимум посещений | Объем вычислений для обычного анализа текущей позиции; большее значение обычно устойчивее, но медленнее |
| Быстрые посещения | Объем вычислений на каждый ход при полном проходе по партии; меньшее значение быстрее строит графики |
| Разнообразие рекомендуемых ходов | Увеличивает разброс кандидатов; `0` дает наиболее стабильный результат, большие значения сильнее распределяют кандидатов |
| Текущая установка | Переключение между установленными сборками KataGo или моделями и удаление ненужных элементов |

### Не запускается или работает медленно

- Сначала попробуйте `OpenCL`; если GPU или драйвер несовместим, переключитесь на `CPU`;
- сборки `CUDA` и `TensorRT` для NVIDIA требуют совместимых драйверов и библиотек;
- выберите меньшую модель с пометкой **самая быстрая**;
- уменьшите **Быстрые посещения** и **Максимум посещений**;
- откройте консоль на левой панели и проверьте точное сообщение об ошибке.

Если проблема сохраняется, создайте [issue в репозитории Ulugo](https://github.com/rinick/ulugo/issues/new), указав операционную систему, модель CPU/GPU, выбранную сборку и ошибку консоли. Документация и история изменений KataGo находятся в [официальном репозитории](https://github.com/lightvector/KataGo).
