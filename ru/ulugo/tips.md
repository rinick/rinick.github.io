На этой странице собраны подсказки из Ulugo, сгруппированные по платформам.

### Общие действия

| Функция | Действие |
| --- | --- |
| Быстрый переход | Удерживать `Shift` и щелкнуть камень, чтобы перейти к поставившему его ходу; щелкнуть будущий ход, чтобы перейти вперед к нему |
| Разметка связанной группы | Выбрать текстовый или графический инструмент и дважды щелкнуть камень, чтобы применить текущую разметку ко всей связанной группе того же цвета |
| Автоматическое изменение текста | Текст разметки автоматически меняется с `A → B` или `1 → 2`; при добавлении правой кнопкой сохраняется текущий текст |
| Исправление ошибочного хода | Выбрать неверный ход и использовать **Заменить ход**. Ulugo вернется к предыдущей позиции, после чего точку можно исправить без повторной расстановки последующих ходов |
| Импорт изображения | При открытии файла выбрать изображение доски, чтобы распознать позицию и создать SGF. Подробнее: [Распознавание доски](./scan.html) |
| Импорт из буфера обмена | Нажать `Ctrl + V`, чтобы напрямую открыть текст SGF или изображение из буфера обмена |

### Веб-версия

| Функция | Действие |
| --- | --- |
| Минимальный режим в портретной ориентации | В портретной ориентации минимальный режим поворачивается на `90°`, оставляя больше места для доски при записи на телефоне или планшете |
| Оценка итогового счета | Щелкнуть ход правой кнопкой на нижней правой панели, чтобы оценить счет позиции; функция предназначена только для позиций в конце партии |

### ИИ-анализ в настольной версии

| Функция | Действие |
| --- | --- |
| Глубокий анализ | Удерживать `Shift` и нажать кнопку анализа справа внизу доски, чтобы игнорировать **Максимум посещений** и продолжать анализ текущей позиции |
| Ценность хода | **Наложение рекомендуемых ходов** может показывать **Ценность** хода. На нее влияют жизнь и смерть в горячей зоне, а также сэнтэ/готэ, поэтому она не полностью совпадает с ценностью йосэ |
| Горячая зона | Включить **Горячую зону**, чтобы показать синим спорные ключевые области, а серым — области, которые, возможно, придется отдать |
| Скорость анализа | При медленной работе выбрать в **Настройках ИИ** меньшую модель KataGo, например `kata1-b18`; уменьшение **Быстрых посещений** также сокращает время построения графиков всей партии |
| Предпросмотр главного варианта | Навести указатель на рекомендованный ход, чтобы увидеть главный вариант; `Alt`-щелчок по точке также показывает его напрямую |

Полный список команд клавиатуры и мыши приведен в разделе [Сочетания клавиш и жесты](./shortcut.html). Значения анализа и графики описаны на странице [ИИ-анализ](./analysis.html).
