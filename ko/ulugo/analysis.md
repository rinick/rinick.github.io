Ulugo 데스크톱 버전은 기보를 로컬에서 분석하고 추천 수, 영역, 집 차이와 승률 변화를 표시합니다. 웹 버전에서는 AI 분석을 사용할 수 없습니다.

처음 사용하기 전에 [AI 실행 환경 설정](./katago.html)을 완료하세요.

### 분석 시작

기보를 연 뒤 바둑판 오른쪽 아래의 번개 버튼을 클릭하거나 `Space`를 누릅니다.

- 기존 수를 빠르게 스캔하여 전체 대국 차트를 만듭니다
- 현재 국면 분석은 계속 진행되며 계산이 늘어날수록 결과가 안정됩니다
- 분석이 끝난 노드는 캐시되어 다시 방문할 때 재계산하지 않습니다
- `Space`를 다시 누르면 분석을 중지합니다

![!600](/en/ulugo/analysis.webp)

`Shift`를 누른 채 분석 버튼을 클릭하거나 `Shift + Space`를 누르면 **심층 분석**을 시작합니다. 현재 국면을 계속 계산하므로 복잡한 변화를 자세히 비교할 때 적합합니다.

### 추천 수

추천 수는 현재 탐색 결과에 따른 후보 수입니다. 원은 후보 순서를 나타내며, 설정의 **추천 수 오버레이**에서 다음 값도 표시할 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| 집 차이 변화 | 최선 후보 대비 예상 집 차이 변화. `0`이 기준이며 `-3.0`은 약 3집 손실 |
| 승률 변화 | 최선 후보 대비 승률 변화. `0%`가 기준이며 음수는 승률 손실 |
| 집 차이 | 착수 후 예상 최종 집 차이를 현재 둘 차례인 쪽의 관점으로 표시. 양수는 우세, 음수는 열세 |
| 방문 수 | 해당 후보에 배분된 탐색 횟수. 탐색 자원과 결과 안정성을 나타내며 후보의 질과 직접 같지는 않음 |
| 가치 | 패스와 비교한 이 수의 가치. 후수 끝내기 가치와 비슷하지만 완전히 같지는 않음 |

추천 수 오버레이는 동시에 두 항목까지 선택할 수 있습니다. **추천 수 오버레이 최소 방문 수**를 설정하면 탐색이 부족해 값이 불안정한 후보를 숨길 수 있습니다.

`Enter`를 누르면 현재 최선의 추천 수를 바로 둘 수 있습니다. 다른 조작은 [단축 조작](./shortcut.html)을 참고하세요.

### 주요 변화

추천 수에 마우스를 올리면 AI가 예상하는 이후 수순을 바둑판에서 미리 볼 수 있습니다. 추천 수를 `Alt` 클릭해도 같은 변화를 표시합니다.

**주요 변화 미리보기 지연**은 마우스를 올린 뒤 변화도가 나타날 때까지의 시간을 조절합니다. `0`으로 설정하면 마우스 오버 미리보기만 꺼지며 `Alt` 클릭은 계속 사용할 수 있습니다.

주요 변화는 현재 탐색이 제시하는 주 진행일 뿐 유일한 후속 수순은 아닙니다. 탐색이 계속되면 달라질 수 있습니다.

### 오른쪽 차트

오른쪽 패널에서 다음 세 차트를 따로 또는 함께 표시할 수 있습니다.

| 차트 | 설명 |
| --- | --- |
| 집 차이 | 매 수 이후의 예상 최종 집 차이. 덤과 현재 규칙을 포함하며 중앙선 위는 `B+`, 아래는 `W+` |
| 손실 집수 | 실전 착수로 발생한 예상 집 차이 손실. 막대가 길수록 손실이 크며 약 1집을 넘는 변화는 강조 표시 |
| 승률 | 매 수 이후 흑의 예상 승률. 백 승률은 `100% − 흑 승률`이며 `50%`가 균형 기준 |

![](/en/ulugo/chart-.webp)

차트에 마우스를 올리면 해당 수의 수순, 집 차이, 양쪽 승률과 손실을 확인할 수 있습니다. 클릭하면 그 수로 바로 이동하고, 차트 위에서 마우스 휠을 사용하면 앞뒤 수를 볼 수 있습니다.

한쪽이 크게 앞선 대국에서는 승률이 오랫동안 `0%` 또는 `100%`에 가까울 수 있습니다. 이 경우 개별 수의 품질은 집 차이와 손실 집수로 비교하는 편이 더 적합합니다.

### 영역과 핫존

| 표시 | 설명 |
| --- | --- |
| 영역 | 반투명 색으로 양쪽이 차지할 것으로 예상되는 구역을 표시. 현재 분석의 판단이며 확정된 종국 계가 결과가 아님 |
| 핫존 | 파란색은 양쪽이 다투거나 실수로 잃을 수 있는 핵심 구역. 회색은 더 중요한 구역을 지키기 위해 포기해야 할 수 있는 부분 |

![!600](/en/ulugo/hot-zone.webp)

### 분석이 느릴 때

먼저 일반 분석이나 전체 대국 스캔의 방문 수를 낮추세요. 모델, 하드웨어와 실행 설정은 [실행 환경 및 하드웨어 설정](./katago.html)을 참고하세요.
