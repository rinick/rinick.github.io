키보드 단축키는 **설정 → 키보드 단축키**에서 변경할 수 있습니다. 아래 표는 기본 키를 보여 줍니다. **데스크톱**으로 표시된 기능은 Electron 데스크톱 앱이 필요합니다.

### 방향키 특수 조작

이전 수, 다음 수와 분기 전환 방향키는 보조 키와 함께 사용할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| 방향키 | 앞뒤로 1수 이동하거나 분기 1개 전환 |
| `Shift + 방향키` | 10수 또는 분기 10개씩 이동 |
| `Ctrl + 방향키` | 시작, 끝, 첫 분기 또는 마지막 분기로 바로 이동 |

macOS에서는 `Ctrl` 대신 `Command`를 사용할 수 있습니다. 이 이동 방식을 유지하기 위해 탐색 기능의 사용자 지정 단축키에는 `Ctrl`이나 `Shift`가 기록되지 않습니다.

### 표식 도구의 특수 조작

| 조작 | 동작 |
| --- | --- |
| 바둑판의 돌을 두 번 클릭 | 현재 문자 또는 도형 표식을 이어진 같은 색 돌 전체에 적용 |
| 지우기 도구로 표식을 두 번 클릭 | 해당 점과 이어진 같은 종류·문자의 표식 삭제 |
| 도구 모음의 지우기 버튼을 두 번 클릭 | 현재 노드의 모든 표식 삭제 |
| 표식 도구 사용 중 기존 표식을 오른쪽 클릭 | 지우기 도구로 바꾸지 않고 해당 점의 표식 삭제 |
| 문자 도구로 빈 점을 오른쪽 클릭 | 현재 문자를 추가하되 표식 문자 자동 증가는 실행하지 않음 |

### 기타 특수 조작

- `Ctrl + V`: 클립보드에서 SGF 또는 이미지 열기. 예약된 단축키이므로 다른 기능에 지정할 수 없음
- `Esc`: 계가 결과를 닫거나 **교대로 두기** 도구로 돌아가기
- 바둑판에서 `Shift + 클릭`: 기존 돌은 그 돌을 둔 수로, 이후 착수는 해당 수까지 이동
- 바둑판 위에서 마우스 휠: 이전 수 또는 다음 수로 이동
- 추천 수를 `Alt + 클릭`: 해당 주요 변화 표시(**데스크톱**)

| 저장 | `Ctrl + S` |
| 대국 정보 | `Ctrl + I` |

### 기보 탐색

| 기능 | 기본 단축키 |
| --- | --- |
| 이전 수 | `↑` |
| 다음 수(주 분기 우선) | `↓` |
| 다음 수(현재 분기 우선) | 미설정 |
| 이전 분기 | `←` |
| 다음 분기 | `→` |

### 착수와 표식

| 기능 | 기본 단축키 |
| --- | --- |
| 패스 | `P` |
| 교대로 두기 | `1` |
| 흑돌 / 백돌 놓기 | `2` / `3` |
| 수 바꾸기 | `4` |
| 문자 / 원 / 사각형 / 삼각형 / 십자 추가 | `5` / `6` / `7` / `8` / `9` |
| 표식 지우기 | `0` |

### 분기 조작

| 기능 | 기본 단축키 |
| --- | --- |
| 현재 분기를 주 분기로 이동 | `\` |
| 분기를 왼쪽 / 오른쪽으로 이동 | 미설정 |
| 다른 분기 정리 | 미설정 |
| 현재 분기 삭제 | `Delete` |
