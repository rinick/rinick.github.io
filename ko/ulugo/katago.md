KataGo는 자체 그래픽 인터페이스가 없는 오픈 소스 바둑 엔진입니다. Ulugo 데스크톱 버전은 KataGo를 로컬에서 실행해 추천 수, 영역, 집 차이 등의 데이터를 얻고 복기 화면에 정리해 표시합니다.

데스크톱 버전을 처음 사용할 때 Ulugo가 권장 KataGo 빌드와 모델을 자동으로 설치하고 선택합니다. 대부분의 사용자는 수동으로 설정할 필요가 없습니다. 준비가 끝나면 [AI 분석](./analysis.html)에서 사용 방법을 확인하세요.

### KataGo와 모델

AI 분석에는 두 구성 요소가 필요합니다.

| 구성 요소 | 역할 |
| --- | --- |
| KataGo | 컴퓨터에서 분석을 실행하는 프로그램 |
| 모델 | 기력과 판단 능력을 저장한 신경망 파일 |

둘 다 로컬에서 실행됩니다. 설치 파일을 내려받을 때는 인터넷 연결이 필요하지만, 설치 후에는 오프라인으로 기보를 분석할 수 있습니다.

### 하드웨어 요구 사항

KataGo는 GPU를 사용하거나 CPU만으로 실행할 수 있습니다. GPU는 필수가 아니지만 일반적으로 분석 속도를 크게 높입니다.

| 컴퓨터 환경 | 권장 선택 |
| --- | --- |
| 비교적 최신 외장 또는 내장 GPU | 호환 범위가 넓은 `OpenCL`을 먼저 시도 |
| 비교적 최신 NVIDIA GPU와 알맞은 드라이버·런타임 | `TensorRT` 또는 `CUDA` 시도 |
| 적합한 GPU가 없고 CPU가 AVX2 지원 | `CPU` 선택 |
| AVX2를 지원하지 않는 구형 CPU | `구형 CPU` 선택. 분석 속도는 더 느림 |
| macOS | Homebrew를 통해 설치하며 Apple Silicon에는 시스템에 맞는 빌드를 사용 |

![!500](/en/ulugo/ai-config.webp)

모델이 크고 동시에 분석하는 내용이 많을수록 일반적으로 메모리를 더 많이 사용합니다. 메모리가 부족하거나 분석이 느리면 **가장 빠름**으로 표시된 모델부터 선택하세요. 디스크에 최소 수백 MB의 여유 공간을 두고, 여러 모델을 설치할 때는 더 많은 공간을 확보하세요.

백엔드에 관한 자세한 내용은 [KataGo 공식 문서](https://github.com/lightvector/KataGo#opencl-vs-cuda-vs-tensorrt-vs-eigen)를 참고하세요.

### 자동 설정과 수동 변경

처음 실행하면 Ulugo가 권장 실행 빌드와 모델을 자동으로 내려받아 선택합니다. 다운로드 중에는 네트워크 연결을 유지해야 하며, 완료 후에는 오프라인 분석이 가능합니다.

다른 빌드나 모델을 사용하려면 **AI 설정**을 엽니다.

1. **KataGo 설치**에서 컴퓨터에 맞는 빌드를 선택해 설치합니다
2. **KataGo 모델**에서 모델을 설치하고 선택합니다
3. **저장**을 클릭한 뒤 바둑판으로 돌아가 분석을 시작합니다

일부 GPU 빌드는 처음 시작할 때 성능 조정을 수행합니다. 이 동안 인터페이스 반응이 느릴 수 있지만 완료 후에는 보통 다시 실행하지 않습니다.

### 주요 설정

| 설정 | 설명 |
| --- | --- |
| 최대 방문 수 | 현재 국면의 일반 분석 계산량. 높을수록 결과가 안정적이지만 느려짐 |
| 빠른 방문 수 | 전체 대국 차트를 만들 때 각 수에 사용하는 계산량. 낮추면 스캔이 더 빨리 끝남 |
| 추천 수 다양성 | 후보 수의 변화를 늘림. `0`이 가장 안정적이며 값이 클수록 후보가 더 분산됨 |
| 현재 설치 | 설치된 KataGo 빌드나 모델을 전환하고 필요 없는 항목을 제거 |

### 시작할 수 없거나 속도가 느릴 때

- 먼저 `OpenCL`을 시도하고 GPU나 드라이버가 호환되지 않으면 `CPU`로 변경
- NVIDIA용 `CUDA`와 `TensorRT` 빌드에는 호환되는 드라이버와 런타임 라이브러리가 필요
- **가장 빠름**으로 표시된 작은 모델 선택
- **빠른 방문 수**와 **최대 방문 수** 낮추기
- 왼쪽 패널의 콘솔에서 구체적인 오류 확인

문제가 계속되면 [Ulugo GitHub Issues](https://github.com/rinick/ulugo/issues/new)에 운영 체제, CPU/GPU 모델, 선택한 빌드와 콘솔 오류를 첨부하세요. KataGo 설명과 변경 기록은 [공식 저장소](https://github.com/lightvector/KataGo)에서 확인할 수 있습니다.
