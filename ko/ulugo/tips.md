이 페이지에서는 Ulugo에 표시되는 팁을 플랫폼별로 정리합니다.

### 일반 조작

| 기능 | 조작 |
| --- | --- |
| 빠른 이동 | `Shift`를 누른 채 바둑판의 돌을 클릭하면 그 돌을 놓은 수로 이동합니다. 이후 수를 클릭하면 해당 수까지 앞으로 이동합니다 |
| 연결된 돌에 표식 | 문자 또는 도형 표식 도구를 사용하는 동안 돌을 두 번 클릭하면 같은 색으로 연결된 돌 전체에 현재 표식을 적용합니다 |
| 문자 표식 자동 증가 | 문자 표식은 `A → B`, `1 → 2`처럼 자동으로 다음 문자로 바뀝니다. 마우스 오른쪽 버튼으로 추가하면 현재 문자를 유지합니다 |
| 수 삽입 | **수 삽입**을 사용하면 하나의 임시 분기에 수를 추가할 수 있습니다. 마우스 오른쪽 버튼을 클릭하면 수를 삭제하고 삭제한 수의 직전 위치로 이동합니다 |
| 수 편집 중 이동 | **수 삽입**이나 **수 삭제**를 선택해도 현재 장면은 바뀌지 않습니다. 두 도구를 전환하거나 현재 분기 또는 그 이전의 본줄기를 선택해도 편집이 계속됩니다. 다른 분기를 선택하면 편집이 종료됩니다 |
| 이미지 가져오기 | 파일을 열 때 바둑판 이미지를 선택하면 장면을 인식하여 SGF를 생성합니다. 자세한 내용은 [바둑판 이미지 인식](./scan.html)을 참조하세요 |
| 클립보드에서 가져오기 | `Ctrl + V`를 누르면 클립보드의 SGF 텍스트나 이미지를 바로 열 수 있습니다 |

### 웹 버전

| 기능 | 조작 |
| --- | --- |
| 세로 화면 미니멀 모드 | 세로 화면에서는 미니멀 모드가 자동으로 `90°` 회전하여 휴대전화나 태블릿에서 기보를 기록할 때 바둑판을 더 크게 표시합니다 |
| 종국 계가 | 오른쪽 아래 창에서 수를 마우스 오른쪽 버튼으로 클릭하면 해당 장면의 집을 계산합니다. 이 기능은 종국 장면에만 적합합니다 |

### 데스크톱 AI 분석

| 기능 | 조작 |
| --- | --- |
| 심층 분석 | `Shift`를 누른 채 바둑판 오른쪽 아래의 분석 버튼을 클릭하면 **최대 방문 수**를 무시하고 현재 장면을 계속 분석합니다 |
| 수의 가치 | **추천 수 오버레이**는 수의 **가치**를 표시할 수 있습니다. 핫존의 사활과 선수·후수가 이 값에 영향을 주므로 끝내기 가치와 같지 않습니다 |
| 핫존 | **핫존**을 켜면 양쪽이 다투는 핵심 영역은 파란색, 포기해야 할 수 있는 영역은 회색으로 표시됩니다 |
| 분석 속도 조절 | 분석이 느리면 **AI설정**에서 `kata1-b18`처럼 더 작은 KataGo 모델을 선택하세요. **빠른 방문 수**를 줄이면 전체 기보 그래프 생성 시간도 단축됩니다 |
| 주요 변화 미리 보기 | 추천 수에 마우스를 올리면 이후의 주요 변화를 미리 볼 수 있습니다. `Alt`를 누른 채 추천 수를 클릭해도 바로 표시됩니다 |

키보드와 마우스의 전체 조작은 [단축 조작](./shortcut.html), 분석 수치와 그래프 설명은 [AI 분석](./analysis.html)을 참조하세요.
