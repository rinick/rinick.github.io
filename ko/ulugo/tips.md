Ulugo 앱에 표시되는 조작 팁을 적용 플랫폼별로 정리했습니다.

### 공통 조작

| 기능 | 조작 |
| --- | --- |
| 빠른 이동 | `Shift`를 누른 채 바둑판의 돌을 클릭하면 그 돌을 둔 수로 이동하고, 이후 착수를 클릭하면 해당 수까지 진행 |
| 이어진 돌 표식 | 문자 또는 도형 도구를 선택한 상태에서 돌을 두 번 클릭하면 이어진 같은 색 돌 전체에 현재 표식을 적용 |
| 표식 문자 자동 증가 | 문자 표식은 `A → B`, `1 → 2`처럼 자동으로 다음 문자로 변경되며, 오른쪽 클릭으로 추가하면 현재 문자를 유지 |
| 잘못 기록한 수 수정 | 잘못된 수를 선택하고 **수 바꾸기**를 사용. Ulugo가 한 수 전으로 돌아가므로 이후 수를 다시 놓지 않고 착점을 수정할 수 있음 |
| 이미지 입력 | 파일을 열 때 바둑판 이미지를 선택하면 국면을 인식해 SGF를 생성. 자세한 내용은 [바둑판 이미지 인식](./scan.html) 참고 |
| 클립보드 입력 | `Ctrl + V`를 누르면 클립보드의 SGF 텍스트 또는 이미지를 바로 열기 |

### 웹 버전

| 기능 | 조작 |
| --- | --- |
| 세로 화면 미니멀 모드 | 세로 화면에서 미니멀 모드가 `90°` 회전해 휴대폰이나 태블릿으로 기보를 기록할 때 바둑판 공간을 더 넓게 확보 |
| 종국 점수 추정 | 오른쪽 아래 패널에서 한 수를 오른쪽 클릭하면 해당 국면의 점수를 추정하며, 이 기능은 종국 국면에만 사용 |

### 데스크톱 AI 분석

| 기능 | 조작 |
| --- | --- |
| 심층 분석 | `Shift`를 누른 채 바둑판 오른쪽 아래 분석 버튼을 클릭하면 **최대 방문 수**를 무시하고 현재 국면을 계속 분석 |
| 착수 가치 | **추천 수 오버레이**에서 수의 **가치**를 표시. 핫존의 사활과 선후수 영향을 받으므로 끝내기 가치와 완전히 같지는 않음 |
| 핫존 | **핫존**을 켜면 양쪽이 다투는 요점을 파란색, 상대에게 넘겨야 할 수 있는 영역을 회색으로 표시 |
| 분석 속도 | 분석이 느리면 **AI 설정**에서 `kata1-b18` 같은 작은 KataGo 모델을 선택. **빠른 방문 수**를 낮추면 전체 대국 차트 생성 시간도 단축 |
| 주요 변화 미리보기 | 추천 수에 마우스를 올리면 주요 변화를 표시하며, 추천 수를 `Alt` 클릭해 바로 표시할 수도 있음 |

전체 키보드와 마우스 조작은 [단축 조작](./shortcut.html), 분석 수치와 차트 설명은 [AI 분석](./analysis.html)을 참고하세요.
